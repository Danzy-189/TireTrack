# TireTracks 3.0.0

Аддон к Create Aeronautics (Offroad): колёса разбивают грунт под собой и поднимают брызги и пыль.

**Minecraft 1.21.1 · NeoForge 21.1.235 · Java 21 · Sable 1.2.2 / Simulated 1.2.1**

## Что делает

* **Дёрн (grass_block)** под колесом превращается в другой блок. Шанс и набор блоков зависят от массы
  машины (кг, шкала Create Aeronautics):

| Класс | Масса | Шанс | Во что превращается дёрн |
|---|---|---|---|
| Лёгкая | 0-45 кг | 12% | земля, песок |
| Средняя | 46-80 кг | 30% | гравий, песок, тропинка (dirt_path) |
| Тяжёлая | больше 80 кг | 50% | грязь (mud), каменистая земля, земля |

  Трава и цветы сверху сносятся.
* **Снег** срезается по одному слою за проход. Полный снежный блок и рыхлый снег сначала становятся
  снегом в 7 слоёв. Когда уходит последний слой, с шансом **25%** грунт под ним превращается в грязь.
  Одиночный слой снега не имеет коллизии, поэтому мод дополнительно проверяет блок над точкой
  контакта - иначе тонкий снег остался бы нетронутым.
* **Частицы из-под колёс** - чисто косметика, блоки и физику не трогают:

| Поверхность | Что летит |
|---|---|
| Вода (в том числе брод) | брызги splash + пузыри |
| Дождь над колесом | капли splash + rain, добавляются к любой поверхности |
| Песок, гравий, тропинка, каменистая земля, песок душ | облако пыли (dust_plume) с оттенком блока |
| Снег, снежный блок, рыхлый снег | снежинки + крошка снега |
| Дёрн, земля, подзол, мицелий, мох | комья земли + немного пыли |
| Грязь, глина, грядка | комья + брызги вместо пыли |
| Камень, дерево, бетон и прочее | слабая потёртость |

  Частицы пропускаются, пока колесо стоит в том же блоке, так что припаркованная машина не пылит.
* Только сторона сервера, с частицами и звуком ломания.

## Как это подключено

Миксин перехватывает у WheelMountBlockEntity ровно один вызов внутри sable$physicsTick:

```java
this.level.getBlockState(extensionToTerrain.minInteractingBlock())
```

Это уже готовая точка контакта колеса с землёй, которую сам Offroad использует для расчёта трения.
Мы через @Redirect отдаём значение как есть, а деформацию и частицы делаем сбоку - физика машины
не меняется.

Класс таргетится по имени (@Pseudo + targets), поэтому проект собирается **без** jar-ников Sable /
Simulated / Offroad, а если класс переименуют - мод просто ничего не делает вместо краша
(require = 0, весь хук обёрнут в try/catch).

Масса машины читается рефлексией через Sable.HELPER -> getContaining -> getMassTracker. Если эта
версия Sable не отдаёт массу, используется средний профиль.

## Настройки

config/tiretracks-common.toml создаётся при первом запуске.

Секция `[general]`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| lightVehicleMaxMass | 45.0 | верхняя граница лёгкой техники, кг (включительно) |
| mediumVehicleMaxMass | 80.0 | верхняя граница средней техники, кг (включительно), выше - тяжёлая |
| lightChance | 0.12 | шанс перекопать дёрн лёгкой машиной |
| mediumChance | 0.30 | шанс перекопать дёрн средней машиной |
| heavyChance | 0.50 | шанс перекопать дёрн тяжёлой машиной |
| snowToMudChance | 0.25 | шанс грязи после последнего слоя снега |
| eatSnow | true | съедать ли снег вообще |
| tickInterval | 4 | раз в сколько физических тиков деформировать грунт (физика тикает часто, не ставь 1) |
| playSounds | true | звук ломания при деформации |
| spawnParticles | true | главный выключатель всех частиц мода |

Секция `[spray]`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| wheelSpray | true | включены ли брызги и пыль из-под колёс |
| sprayInterval | 2 | раз в сколько физических тиков выпускать порцию частиц на колесо |
| sprayDensity | 2 | множитель количества частиц в порции (больше - плотнее, дороже по производительности) |

## Сборка .jar

Нужен JDK 21.

```bash
gradle wrapper --gradle-version 8.10   # один раз, если нет ./gradlew
./gradlew build
```

Готовый файл: **build/libs/TireTracks-3.0.0.jar**

Или открой папку как Gradle-проект в IntelliJ IDEA (File - Open) и запусти задачу build.
Первая сборка качает NeoForge 21.1.235 и декомпилирует Minecraft, это 5-15 минут.

Хочешь автодополнение по классам Sable/Simulated/Offroad - положи их jar в libs/ и раскомментируй
строку compileOnly fileTree(...) в build.gradle.

## Если в игре ничего не происходит

1. В логе должно быть "TireTracks 3.0.0 loaded".
2. Проверь mod id зависимостей в своей сборке (sable / simulated / offroad). Они помечены как
   optional, так что ошибка в id не мешает запуску, но и порядок загрузки не гарантирует.
3. Если Offroad обновится и переименует sable$physicsTick или уберёт вызов getBlockState,
   хук молча отключится. Тогда правь method = "sable$physicsTick" в WheelMountBlockEntityMixin.
4. Если техника попадает не в тот класс - масса могла не прочитаться, и мод работает по среднему
   профилю. Подкрути границы в конфиге.
5. Частиц не видно на медленном ходу - это нормально: порция выпускается при въезде в новый блок.
   Уменьши sprayInterval или подними sprayDensity.
